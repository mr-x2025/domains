# 🌐 برنامج إدارة وتوليد وفحص الدومينات

برنامج ويب متكامل بلغة PHP لتوليد وإدارة وفحص أسماء النطاقات (الدومينات) مع واجهة عربية كاملة وثيم داكن.

## 📋 المميزات الرئيسية

- ✅ **واجهة عربية كاملة** مع دعم RTL
- ✅ **ثيم داكن** متناسق وجذاب
- ✅ **5 أنواع مختلفة** لتوليد الدومينات
- ✅ **فحص توافر الدومينات** مع WHOIS
- ✅ **Context Menu** في جميع الجداول
- ✅ **تصدير CSV** ونسخ للحافظة
- ✅ **إحصائيات تفصيلية** لكل نوع
- ✅ **JavaScript مدمج** داخل ملفات PHP (لا توجد ملفات .js منفصلة)

## 📁 هيكل المشروع

```
domains/
├── index.php                    # الواجهة الرئيسية مع نظام التبويبات
├── geo_domains.php              # توليد دومينات جغرافية
├── exact_match.php              # توليد دومينات Exact Match
├── brand_domains.php            # توليد دومينات البراند
├── pattern_domains.php          # توليد دومينات بنمط 5 أحرف
├── checker.php                  # فحص توافر الدومينات
└── data/                        # مجلد البيانات
    ├── الدول الاوروبيه ومدنها.txt
    ├── كلمات مفتاحيه جيو دومين.txt
    ├── مدن استراليا.txt
    ├── مدن المملكه المتحده.txt
    ├── مدن كندا.txt
    └── مدن وولايات امريكا.txt
```

## 🚀 التشغيل

### المتطلبات
- PHP 7.4 أو أحدث
- خادم ويب (Apache/Nginx) أو PHP Built-in Server

### التثبيت

1. استنساخ المشروع:
```bash
git clone https://github.com/mr-x2025/domains.git
cd domains
```

2. تشغيل خادم PHP المدمج:
```bash
php -S localhost:8000
```

3. فتح المتصفح على:
```
http://localhost:8000/index.php
```

## 📖 دليل الاستخدام

### 1️⃣ جيو دومين (Geo Domains)

توليد دومينات جغرافية بناءً على:
- **5 دول**: USA, Canada, UK, Australia, Europe
- **أكبر المدن** حسب عدد السكان
- **100 كلمة مفتاحية** جغرافية
- دعم صيغة `@@@` لاستبدال اسم المدينة

**مثال**: `VisitNewYork.com`, `ChicagoHotels.com`

### 2️⃣ إكزاكت ماتش دومين (Exact Match)

توليد دومينات بدمج كلمات من نيتشات مختلفة:
- **7 نيتشات**: المال، الكريبتو، العقار، التسويق، التكنولوجيا، الصحة، التعليم
- **11 مجموعة** من الكلمات القوية (Power Words)
- التحكم في طول وترتيب الكلمات

**مثال**: `CryptoPro.com`, `FinanceHub.com`

### 3️⃣ دومين براند (Brand Domains)

توليد أسماء براند إبداعية:
- **نمط CVCVC**: 5 أحرف متناوبة (حرف ساكن - متحرك)
- **براند مركّب**: دمج Prefixes + Suffixes
- **توليد عشوائي**: أطوال متنوعة

**مثال**: `Neoly.com`, `Hyperzo.com`, `Balon.com`

### 4️⃣ نمط 5 أحرف (Pattern Domains)

توليد دومينات بأنماط محددة:
- **CVCVC**: حرف ساكن - متحرك - ساكن - متحرك - ساكن
- **CVCCV**: حرف ساكن - متحرك - ساكن - ساكن - متحرك
- التحكم في تكرار الأحرف

**مثال**: `tisuk.com`, `belta.com`

### 5️⃣ فحص الدومينات (Domain Checker)

فحص توافر الدومينات:
- استقبال دومينات من جميع الصفحات
- فحص متوازي مع DNS Lookup
- إحصائيات مباشرة (متاح/محجوز)
- تصفية وتصدير النتائج
- شريط تقدم مباشر
